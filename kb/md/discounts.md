# Northwind Goods Discounts Policy

## 1. Welcome Discount

New customers can use the code WELCOME10 to receive 10% off their first order. This code requires a minimum order of $30.

## 2. Using Discount Codes

* Only one discount code can be used per order.
* Discount codes cannot be combined with each other.
* Discount codes are not valid on sale items.

## 3. Newsletter Subscribers

Newsletter subscribers receive a new discount code every month.

## 4. Expiration of Discount Codes

Discount codes expire 30 days after they are issued.

## 5. Price Adjustments

If an item's price drops within 7 days of purchase, we will refund the difference on request.

## 6. Gift Cards

Gift cards cannot be used to buy other gift cards.
